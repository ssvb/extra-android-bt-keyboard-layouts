# Extra Physical Keyboard Layouts for Android

This APK package adds a few choices to the list of layouts to use when a physical keyboard is
connected e.g. via OTG or Bluetooth.

As an interesting "poor man's" solution, tools like [EmuBTHID](https://github.com/Alkaid-Benetnash/EmuBTHID)
can be used to export the physical keyboard of a Linux laptop or PC over Bluetooth, presenting it to
an Android device as a fully functional Bluetooth keyboard.

Note: this project is a stripped down fork of https://github.com/calin-darie/extra-keyboard-layouts
(you can go there if you want to support the original author via starring that project or donating money).

# Documentation

The official Android documentation describes the `kcm` file format:
https://source.android.com/docs/core/interaction/input/key-character-map-files

# Privacy Policy

Extra Physical Keyboard Layouts does not collect any data.

There's no communication initiated by Extra Physical Keyboard Layouts.

The Android system asks for keyboard layouts, and the app responds with some. That's it.

Stay private, stay safe, and have fun!
